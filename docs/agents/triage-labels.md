# Triage Labels

各 skill 使用五个标准 triage 角色来交流。本文档将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| Skill 中的标签              | 本仓库标签             | 含义                     |
| -------------------------- | -------------------- | ------------------------ |
| `needs-triage`             | `needs-triage`       | 维护者需要评估            |
| `needs-info`               | `needs-info`         | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，Agent 可直接领取 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现              |
| `wontfix`                  | `wontfix`            | 不会处理                  |

当 skill 提及某个角色（如"打上 AFK-ready 的 triage 标签"）时，使用此表对应的标签字符串。

如实际标签词汇有变化，直接修改右栏即可。
